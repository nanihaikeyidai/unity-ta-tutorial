How to use

推荐学习路径

  1. URP · Forward+：先看管线动画，建立「一帧里发生了什么」的顺序感。
  2. 性能 · Batcher / Overdraw：同一套场景，理解 CPU 提交与 GPU 填充率两个瓶颈。
  3. Shader · Fresnel / Dissolve：把数学写成画面，再对照 HLSL 片段落地到 URP Unlit / Lit。

本站为纯静态页面，无需后端。语音依赖本机浏览器的语音引擎（推荐 Chrome / Edge）。
