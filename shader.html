Shader 技术：把公式变成光影

LESSON 01

PBR 速通：别被名词吓到

PBR 用几张贴图描述材质——URP Lit 已接好 BRDF，TA 要保证作者向与数值区间正确。

  • Base Color：反照率，金属的彩色在这里，绝缘体避免过亮
  • Metallic：0 绝缘体 / 1 金属（少用中间灰除非特殊）
  • Smoothness：高光锐利度（= 1 − Roughness）
  • Normal / AO / Emission：细节、缝隙、自发光
🧱 隐喻：Base Color 是油漆颜色，Smoothness 是打磨程度，Metallic 是「这块到底是不是铁」。
URP Lit 输入心智Checklist
_BaseMap     // sRGB
_BumpMap     // 线性，不要当 sRGB
_Metallic    // 0..1
_Smoothness  // 0..1，越光滑高光越尖
LESSON 02

法线贴图：平面上「骗」出凹凸

法线贴图不改顶点，只在像素阶段扰动法线 → 轮廓仍平，明暗却有砖缝。

  • 导入必须标 Normal map
  • 注意 OpenGL / DirectX 绿通道方向
  • 强度过大 → 油腻反光；过小 → 像没贴
Sample normalHLSL
float3 nTS = UnpackNormal(SAMPLE_TEXTURE2D(_BumpMap, sampler_BumpMap, uv));
nTS.xy *= _BumpScale;
float3 nWS = TransformTangentToWorld(nTS, tangentWS);
🔴 Live · Normal Mapping
黄点 = 灯光方向。几何是平面，明暗来自 per-pixel 法线。
LESSON 03

Fresnel：边缘为什么会亮

视线掠过表面时反射变强 —— 常用近似：

Fresnel = pow(1 - saturate(dot(N, V)), Power)

🫧 隐喻：肥皂泡正对你几乎透明，侧过来才五彩反光——这就是菲涅尔。
  • Power 大 → 亮边窄、贴轮廓
  • 用途：护盾、描边光、车漆、皮肤边缘
Fresnel rimHLSL
float fresnel = pow(1.0 - saturate(dot(N, V)), _Power);
float3 col = lerp(baseCol, _RimColor.rgb, fresnel);
🔴 Live · Fresnel Sphere
提高 Power：亮边变窄。灯光缓慢旋转以显示漫反射与边缘分离。
LESSON 04

Dissolve：噪声剪裁 + 灼烧边缘

采样噪声，与阈值比较，clip 掉低于阈值的像素；阈值附近加亮边 = 灼烧感。

  • 噪声分辨率与 tiling 决定「块」大小
  • 边缘宽度用 smoothstep 做软硬
  • clip 可能影响 Early-Z，大面积慎用
DissolveHLSL
float n = SAMPLE_TEXTURE2D(_Noise, sampler_Noise, uv).r;
clip(n - _Threshold);
float edge = smoothstep(_Threshold, _Threshold + _Edge, n);
col = lerp(_BurnColor, col, edge);
🔴 Live · Dissolve
自动来回溶解；拖动滑杆可接管。亮边 = burn edge。
