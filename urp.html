URP 管线：把一帧拆开看

Universal Render Pipeline 不是「一个黑盒开关」，而是一条可插入、可裁剪的渲染流水线。本章用动画把 Forward+ 的顺序、Renderer Feature 的挂载点讲清楚。

本课目录

01 · Forward+ 概览 02 · Renderer Features 03 · 灯光与阴影 04 · 后处理 05 · Camera Stack
LESSON 01

Forward+：一帧的流水线

URP 在较新版本默认走向 Forward+（Forward Plus）。你可以把它想成工厂流水线：

🏭 隐喻：每一帧 = 一条传送带。物体先过安检（Culling），再盖章（Shadow / Depth），再按货架分区取灯（Cluster），最后上色包装（Opaque → Post）。
  • Culling：视锥 + 遮挡，丢掉看不见的 Renderer
  • Shadow Maps：主光 / 附加光阴影图
  • Depth Prepass（可选）：先写深度，减少后续 overdraw
  • Light Clustering：屏幕空间分簇，像素只采附近灯
  • Opaque → Sky → Transparent → Post

和经典 Forward 的核心差别：灯光不再「整场景按数量硬顶」，而是按像素邻域取灯列表——中等规模多光源更友好。

LESSON 02

Renderer Features：往流水线「插插座」

Renderer Feature 是 URP 扩展渲染的第一公民。不必 fork 整条管线，在 Universal Renderer Data 上挂 Feature，即可在指定时机注入 ScriptableRenderPass。

🔌 隐喻：Renderer = 插线板。Feature = 插头。插错孔（错误的 RenderPassEvent）就会读到空 RT 或盖住不该盖的东西。
  • 描边 / 外轮廓：常在 Opaque 后、Sky 前
  • 全屏 Blit：注意 _CameraColorTexture 是否已声明
  • 顺序敏感：列表里 Feature 的上下 ≈ Pass 先后
OutlineFeature.csC#
public class OutlineFeature : ScriptableRendererFeature {
  public override void AddRenderPasses(
      ScriptableRenderer renderer, ref RenderingData data) {
    // 选择注入时机
    _pass.renderPassEvent = RenderPassEvent.AfterRenderingOpaques;
    renderer.EnqueuePass(_pass);
  }
}

LESSON 03

灯光与阴影：主光一条，附加光一筐

URP 里主方向光通常一盏走完整阴影级联；附加光有数量与阴影预算。Forward+ 用聚类减轻多灯着色压力，但：

  • 阴影图分辨率 / 级联数 / 软阴影采样 → 直接吃带宽
  • 用 Light Layer 与 Culling Mask 把无关物体剔出 ShadowCaster
  • 移动端优先：少实时阴影，烘培 + 少量 blob
🔦 隐喻：主光是太阳（贵但全球受益），附加光是台灯（多了要按桌分区供电——这就是 Cluster）。

LESSON 04

后处理：美的代价是全屏带宽

Bloom、Color Grading、Vignette、AO、DoF——多是全屏或近全屏操作。Volume 按优先级混合，但每个开启的效果都在吃填充率。

  • 移动端优先：Tonemapping + 轻 Bloom；慎开 SSAO / 重 DoF
  • Bloom 阈值比强度更伤性能
  • 用 Volume Profile 分层：全局底子 / 区域覆盖 / 剧情镜头
🎨 隐喻：后处理是「整张照片的滤镜」。滤镜越多，冲洗店越忙——GPU 同理。
LESSON 05

Camera Stack：UI 与世界叠在一起

Base Camera 清屏 + 主场景；Overlay Camera 把 UI / 特效叠上去。Stack 能避免 UI 被后处理污染，也能分层世界特效与 Screen Space UI。

  • 代价：多一次提交、可能的 RT 切换
  • 坑：Overlay 误开 Post、深度不清 UI 被挡、HDR/LDR 混叠
  • UI Camera 通常关阴影、关后处理、清深度按需
Camera setupChecklist
Base  : RenderType = Base,  Post = true,  Clear = Skybox
Overlay: RenderType = Overlay, Post = false, ClearDepth = true
